## Overview

Adobe Lightroom Classic is aimed at photographers and other image-focused creators who need one desktop environment for both organizing extensive photo collections and refining images with control. It brings together catalog management and editing tools so the path from import to export stays inside a single application.

This macOS release is centered on everyday production work: RAW handling, reversible edits, and Apple Silicon support. The result is a workflow that keeps source files unchanged while helping you manage and process a growing library efficiently.

## Usage

- Import photos into a catalog to begin managing your library.
- Apply RAW adjustments, color edits, and local corrections to selected images.
- Use AI masking and other selective tools when you need targeted edits.
- Run batch operations to apply consistent changes across a set of photos.
- Export finished images after reviewing edits in the catalog.

Typical workflow:
1. Add a folder or card import to the photo catalog.
2. Sort, rate, and tag images for easier selection.
3. Edit images with non-destructive controls.
4. Sync or exchange assets through Creative Cloud when needed.
5. Export final files in the desired format.

## FAQ

**How do I get the latest version?**

**Where are my edits stored?**  
Edits are handled non-destructively, so the original image files are preserved while adjustments are tracked through the catalog and project data.

**Can I move my catalog to another machine?**  
Yes, but you should keep the catalog and associated image files together or relink them carefully after moving.

**What if the app does not start correctly?**  
Check your macOS version, confirm the build matches your hardware, and verify that the extracted files were not moved or renamed after download.
